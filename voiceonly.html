사용 방법은 딱 네 단계

사이트에서 실행 버튼을 누른 다음, 열린 Colab 화면에서 작업해줘.

01 / OPEN

Colab 열기

위의 실행 버튼을 눌러 노트북을 열어. Google 계정 로그인이 필요할 수 있어.

02 / RUN

전체 실행

상단의 런타임 → 모두 실행. 가능하면 GPU를 선택하면 좋아.

03 / UPLOAD

음원 업로드

Colab 두 번째 단계에서 MP3, WAV, FLAC, M4A 파일 하나를 골라.

04 / SAVE

듣고 다운로드

보컬·반주를 미리 듣고 결과를 ZIP으로 받아. WAV 포함 여부도 선택 가능해.

중요: 이 GitHub Pages 자체에서는 음악 파일을 업로드하거나 AI 분리를 실행하지 않아. 버튼으로 열린 Google Colab에서 업로드·분리·다운로드가 이루어져. GitHub에는 voiceonly.html과 VoiceKeeper_Colab.ipynb를 저장소의 최상위에 함께 올려야 실행 링크가 정상 작동해. 기존 index.html은 그대로 유지해.
